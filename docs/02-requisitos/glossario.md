# Glossário

| Termo | Definição |
|---|---|
| Oficina | Oferta pedagógica reutilizável que descreve tema, objetivo, conteúdo e carga horária prevista. |
| Turma | Execução calendarizada de uma oficina, com vagas, local, datas e instrutores. |
| Encontro | Aula ou atividade que compõe o cronograma de uma turma. |
| Participante | Jovem elegível que frequenta ou pretende frequentar uma turma. |
| Responsável | Pessoa legalmente vinculada a um participante menor de idade. |
| Instrutor | Usuário que conduz uma ou mais turmas e registra informações acadêmicas. |
| Inscrição | Vínculo entre participante e turma, com situação e datas próprias. |
| Vaga ocupada | Inscrição confirmada que consome uma unidade da capacidade da turma. |
| Lista de espera | Fila ordenada de inscrições elegíveis que aguardam vaga. |
| Frequência | Resultado de presença de um participante em um encontro realizado. |
| Projeto | Entrega prática individual criada durante uma turma. |
| Avaliação | Nota e devolutiva final atribuídas ao participante. |
| Concluinte | Participante que atendeu a frequência, nota e entrega de projeto exigidas. |
| Certificado | Documento emitido para uma inscrição concluída com aprovação. |
| MVP | Menor versão funcional capaz de cumprir o objetivo acadêmico e validar a solução. |
| Arquivamento | Retirada de um cadastro do uso corrente sem apagar seu histórico. |
