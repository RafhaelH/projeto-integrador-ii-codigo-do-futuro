# Checklist de execução

Estado: **aguardando avaliação humana**. Os itens abaixo estão desmarcados para execução pelo responsável.

- [ ] Escolher cinco pessoas reais; obter ciência para uso acadêmico e autorização de gravação se aplicável.
- [ ] Registrar versão publicada, data, URL e dispositivo em cada ficha.
- [ ] Fazer backup do banco exclusivo deste projeto antes das sessões.
- [ ] Conferir contas e credenciais restritas, entregando somente o acesso individual.
- [ ] Conferir prazos de inscrição e estado de cada turma exclusiva.
- [ ] Confirmar que A01/A02 atuarão apenas nos registros próprios do roteiro.
- [ ] Preservar cenários de captura e dados dos demais avaliadores.
- [ ] Disponibilizar PDF/HTML imprimível e roteiro correto.
- [ ] Registrar tentativa inicial, dificuldade, ajuda, falhas e não execução por tarefa.
- [ ] Observar celular/teclado quando apropriado, sem declarar auditoria completa de acessibilidade.
- [ ] Recolher opiniões reais e deixar respostas ausentes em branco.
- [ ] Sanitizar evidências; guardar identidade real privadamente.
- [ ] Consolidar achados com denominadores, perfil e limitações.
- [ ] Registrar decisões, correções e retestes antes da versão definitiva.
- [ ] Reconfirmar versão do manual/vídeo; sem promoção automática para main.
