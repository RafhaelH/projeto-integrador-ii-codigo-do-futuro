## Como completar depois das sessões

1. Selecionar cinco colegas de curso/profissionais distintos; coletar nome, condição, data, versão e ambiente no original privado para o tutor.
2. Preservar o que cada pessoa testou/funcionou, testou/falhou e correção sugerida, não testou/motivo, sugestões/evidências. Campos não respondidos ficam ausentes com explicação, não “aprovado”.
3. Reunir as cinco fichas originais, [consolidação](consolidacao.md) e [registro de decisões](registro-de-melhorias.md), com referências de alterações/retestes quando pertinentes.
4. Gerar PDF definitivo para submissão, renderizar e conferir todas as páginas, nomes/datas/campos e links/evidências. Usar título “Consolidação das cinco avaliações reais”, versão e data efetivas; guardar fonte e hash do arquivo final.
5. Preservar nomes/originais no material destinado ao tutor. Publicação no Git de identidade/opiniões reais exige autorização; eventual cópia pública anonimizada não substitui original identificado solicitado pela disciplina.
