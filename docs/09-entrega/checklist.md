# Checklist da entrega acadêmica

## Situação 1 — Revisão e preparação

- [x] Tema e problema definidos
- [x] Justificativa e objetivos definidos
- [x] Público-alvo identificado
- [x] Escopo e fora do escopo documentados
- [x] Requisitos funcionais documentados
- [x] Requisitos não funcionais documentados
- [x] Regras de negócio documentadas
- [x] Perfis e permissões definidos
- [x] Critérios de aceite documentados
- [x] Casos de uso definidos
- [x] Modelo conceitual inicial
- [x] Modelo lógico inicial normalizado
- [x] Dicionário de dados inicial
- [x] Arquitetura definida
- [ ] Protótipos das telas
- [ ] Revisão final dos diagramas após implementação
- [x] Projeto físico inicial gerado pelas migrações

## Situação 2 — Desenvolvimento

- [x] Repositório GitHub criado
- [x] Estratégia de branches e commits definida
- [x] Fundação Django criada
- [x] PostgreSQL configurado
- [ ] Autenticação e autorização por perfil em todos os módulos
- [x] Participantes, responsáveis, instrutores e instituições
- [x] Oficinas, turmas e encontros
- [x] Inscrições, vagas e lista de espera
- [x] Frequência
- [ ] Projetos
- [ ] Avaliações e conclusão
- [ ] Certificados
- [ ] Painéis e relatórios
- [ ] Interface responsiva em todos os módulos
- [ ] Tratamento de erros
- [ ] Dados fictícios de demonstração
- [ ] Testes automatizados de todos os requisitos Must
- [x] Integração contínua configurada
- [ ] Ambiente publicado

## Situação 3 — Validação e melhoria

- [x] Estratégia de verificação definida
- [x] Plano de avaliação definido
- [x] Formulário-base criado
- [ ] Cinco avaliadores selecionados
- [ ] Cinco avaliações executadas
- [ ] Bugs e sugestões consolidados
- [ ] Correções priorizadas e implementadas
- [ ] Sugestões recusadas justificadas
- [ ] Testes de regressão executados
- [ ] PDF com as cinco avaliações

## Documentação final

- [ ] README de instalação e uso atualizado
- [ ] Diagramas refletindo a aplicação final
- [ ] Dicionário de dados refletindo as migrações finais
- [ ] Evidências de testes automatizados
- [ ] Evidências de testes manuais
- [ ] Manual do usuário com screenshots
- [ ] Relatório acadêmico final
- [ ] Link público ou autorizado do GitHub
- [ ] Link da aplicação publicada

## Vídeo

- [ ] Roteiro final preparado
- [ ] Narração feita pelo autor
- [ ] Problema, público e objetivo apresentados
- [ ] Principais funcionalidades demonstradas
- [ ] Tecnologias e arquitetura explicadas
- [ ] Testes e avaliações mencionados
- [ ] Melhorias implementadas apresentadas
- [ ] Duração próxima de cinco minutos
- [ ] Links testados antes da entrega

## Critérios antes de marcar a versão final

- [ ] Todos os itens Must concluídos
- [ ] Nenhum erro crítico ou alto aberto
- [ ] Migrações aplicam em banco vazio
- [ ] Testes passam em ambiente limpo
- [ ] Segredos não estão no Git
- [ ] Dados pessoais das evidências estão anonimizados
- [ ] Código, documentação e vídeo representam a mesma versão
